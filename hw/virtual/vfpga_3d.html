VFPGA-L1 virtual board

A simulated FPGA sized for the three-layer L design. The 3D floorplan shows where each layer's logic, block RAM and multipliers sit, replays real simulated jobs, and lists what the virtual tests found. Everything here is simulation and synthesis estimates, no board.

Drag to rotate, scroll or pinch to zoom. Jobs replayed are real RTL simulation results (cycles per image from the two-stage system, matrix products from the Forge tile). The split of the shared system module between Cortex stage 1 and L Deep is an estimate; the memory split is exact by size.
